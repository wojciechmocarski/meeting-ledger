This file exists so Claude Code picks up the project conventions.

The conventions are vendor-neutral and live in one place:

-> see [`../AGENTS.md`](../AGENTS.md)

Read AGENTS.md before working in this repo. It covers the project goal, the
four-phase pipeline, the anti-hallucination rules, the editorial rules, what
must never be committed, and the repository structure.

Using a different assistant or tool? AGENTS.md lists where each tool reads its
instructions (Cursor, Copilot, etc.). Nothing here is Claude-specific except the
filename.
