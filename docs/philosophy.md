# Philosophy

## Gall's Law

> "A complex system that works is invariably found to have evolved from a
> simple system that worked. A complex system designed from scratch never works
> and cannot be patched up to make it work. You have to start over with a
> working simple system."
> - John Gall, *Systemantics* (1975)

This pipeline was not designed top-down. It grew from a single working step -
"turn one transcript into one good note" - and accreted phases only as each
previous one proved itself in real engagements. Adopt it the same way: start
with phase 1 on one meeting. Add the rest when you feel the need.

## Context engineering = curation

The most important skill for a consultant working with AI is not prompt
engineering. It is **selecting what enters context**.

A model's output is bounded by what you put in front of it. The leverage is in
curation: the right glossary, the right prior notes, the right process document
- and nothing else. This pipeline is a curation mechanism built into file
architecture. The folder structure decides what is easy to pull into context
and what stays out.

## Anti-hallucination as a project standard

Three rules apply to every assistant interaction in this pipeline:

1. If the data is not in the files - say "I don't have this in the files".
2. If you propose something - mark it as a proposal, not a fact.
3. When citing - give the source ("according to {file}...").

Never invent client names, numbers, dates, or deliverables. When unsure - ask.
Documentation that quietly fabricates is worse than no documentation: it gets
trusted.

## Themes over chronology

Notes and process docs are organized by topic, not by the order things were
said. A reader six months later wants "what was decided about X", not a
timeline of the conversation. This single rule does more for long-term
usefulness than any formatting.

## One direction of authority

Each fact has one home. The note is the source for decisions; the data-flow
document is the source for technical detail; the glossary is the source for
naming. Other documents reference, they do not duplicate. Duplication is where
inconsistency breeds.
