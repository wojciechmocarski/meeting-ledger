# Example: IT / integration delivery

The original, most demanding use case: a software/integration engagement where
meetings produce technical agreements that must land in process and data-flow
documentation, then export to Word deliverables (DFD / BPMN / sequence
diagrams).

- `20260507-acme-mtg-internal-invoice-flow/` - a meeting and its note
- `proj-data-flows/` - the source documents (process overview + data flow with
  Mermaid diagrams)
- `_index.md`, `people.md` - the workspace map and people registry

This is the heaviest domain. If the pipeline holds here, it holds in lighter
ones - see the sibling `marketing-agency/` and `law-firm/` examples for the same
mechanics with much simpler source documents.
